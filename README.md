# 📊 E-Commerce Data Analytics Project (DEPI)

---

## 🌟 Overview
This project is part of the **Digital Egypt Pioneers Initiative (DEPI)**.  
It aims to transform raw, unstructured e-commerce data into actionable business insights using a comprehensive data pipeline.

The analysis covers:
- Customer behavior  
- Sales performance  
- Payment methodologies  
- Logistics efficiency  

---

## 🛠️ Tech Stack

The project was implemented through three analytical tracks:

### 🔹 Programming & Preprocessing
- Python (Pandas, NumPy, Seaborn, Matplotlib)

### 🔹 Database Management
- SQL Server (ETL process, complex querying, data modeling)

### 🔹 Business Intelligence & Visualization
- Power BI  
- Tableau  
- Microsoft Excel  

---

## 📈 Key Performance Indicators (KPIs)

- **Total Revenue:** $16.01M  
- **Total Unique Orders:** 99,441  
- **Average Order Value (AOV):** $161  
- **Average Shipping Cost:** $20  
- **Average Delivery Time:** 12.5 days  
- **Average Review Score:** 4/5  

---

## 📂 Project Structure

### 🔹 Data Cleaning & EDA (Python)
- Handling missing values  
- Data type conversion  
- Feature engineering  

### 🔹 Database Design (SQL)
- Relational schema (1:N relationships)  
- ETL pipeline from Python to SQL Server  

### 🔹 Visualization Dashboards
- **Power BI:** Executive performance dashboards  
- **Tableau:** Geographic and logistics analysis  
- **Excel:** Operational reporting  

---

## 💡 Top Insights

- **Geographic Hub:** São Paulo leads with 15.5K+ customers  
- **Revenue Growth:** Peak reached $1.19M in Nov 2017  
- **Payment Behavior:** Credit Cards represent ~78% of revenue  
- **Customer Experience:**  
  - Delivered Orders → Avg Rating: 4/5  
  - Processing Orders → Avg Rating: 1/5  

---

## 🚀 Strategic Recommendations

- **Logistics:** Expand warehouses in São Paulo & Rio de Janeiro  
- **Marketing:** Schedule campaigns on Mon–Tue mornings  
- **FinTech:** Promote Boleto payments for liquidity  
- **Customer Retention:** Improve communication during processing stage
